# رِفاد | إدارة البلاغات

لوحة عربية لمتابعة البلاغات المدرسية، حالة اتفاقية مستوى الخدمة، التحليلات، المدارس، والمستخدمين.

## التشغيل

1. استخدم Node.js 22.5 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` واضبط `SESSION_SECRET` عشوائيًا بطول 32 محرفًا أو أكثر، و`INITIAL_ADMIN_SETUP_TOKEN` سرًا عشوائيًا مستقلًا بطول 32 محرفًا أو أكثر.
4. نفّذ `npm run dev` وافتح العنوان الذي يظهره Vite.
5. أنشئ حساب المسؤول بإدخال رمز التهيئة السري. لا يمكن بدء التهيئة إذا لم يُضبط الرمز في بيئة الخادم، ولا توجد كلمات مرور أو حسابات افتراضية. أزل `INITIAL_ADMIN_SETUP_TOKEN` من بيئة التشغيل بعد إنشاء المسؤول.

يخزن التطبيق البيانات في `data/rifad.sqlite`. لا تضع ملف قاعدة البيانات أو `.env` في مستودع عام. للنشر استخدم HTTPS وسر جلسة خاصًا ونسخًا احتياطيًا مشفرًا، واضبط رمز التهيئة قبل بدء الإعداد الأول فقط.

## استيراد البيانات

- من صفحة البلاغات، ارفع ملف CSV بترميز UTF-8. الاستيراد قابل للتكرار ويطابق البلاغات بمعرّف الحالة.
- لا يحذف التطبيق البلاغات تلقائيًا. الحذف الإداري إخفاء منطقي مع الاحتفاظ بالسجل.
- من صفحة المدارس، ارفع CSV يحتوي على الأقل على رقم المدرسة واسمها؛ يمكن إضافة المشرف والمنطقة.
- يبدأ الخادم بمزامنة شيت المدارس الافتراضي المقدم من Shalfa عند التشغيل، ثم يمكن للمسؤول إعادة المزامنة يدويًا من صفحة المدارس أو تغيير الرابط من الإعدادات.
- يتعرف استيراد شيت المدارس على الأعمدة الحالية `الرقم الوزاري` و`اسم الموقع` و`مشرف الشركة` و`العنوان`.
- من لوحة التحكم، فلتر البلاغات المفتوحة حسب المشرف أو الطبقة أو المنطقة، ثم نزّل صورة PNG عالية الدقة أو شاركها مباشرة من الأجهزة والمتصفحات الداعمة.
- تظهر تنبيهات البلاغات التي بقي على SLA الخاص بها ساعتان أو أقل، ويتم تحديثها تلقائيًا كل دقيقة أثناء فتح لوحة التحكم.
- يستطيع كل مستخدم تحديث اسمه واسم المستخدم وكلمة مروره من صفحة «حسابي»؛ يتطلب ذلك كلمة المرور الحالية، ويؤدي تغيير كلمة المرور إلى إنهاء الجلسات الأخرى.
- تقارير المدارس قابلة للتنزيل كصورة PNG، كما يمكن تنزيل سجل تغييرات بيانات المدرسة بصيغة CSV.
- يتطلب التحديث كل ساعة تصديرًا دوريًا من منصة الدعم وإعادة استيراده؛ لا تتوفر وصلة API أو اعتماد رسمي للمنصة ضمن بيانات المشروع.
- حقول مدة SLA الرقمية وتاريخ الحل اختيارية. عند غياب المدة يعرض التطبيق «غير متاح»، ويستخدم حقل «بحاجة إلى الانتباه» كإشارة فقط.

## التحقق

- `npm test` — اختبارات قراءة التصدير العربي، التهيئة الآمنة، الحسابات، الاستيراد المتكرر، الربط بالمدارس، وسجل التغييرات.
- `npm run build` — بناء الواجهة للإنتاج.

## النشر

للنشر على Vercel مع الاحتفاظ بخادم Express وقاعدة SQLite على قرص دائم، اتبع [دليل النشر](./DEPLOYMENT.md). لا تنشر قاعدة SQLite المحلية على Vercel؛ وظائف Vercel لا توفر تخزينًا دائمًا لملفات التطبيق.
